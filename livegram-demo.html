🤖 Livegram — anonim ikki tomonlama chat

Foydalanuvchi username yozmaydi, o'zi anonim qoladi — lekin siz Telegram'da unga javob qaytara olasiz. Kod yozilmaydi, server kerak emas. Quyida saytdagi ko'rinishi va sozlash bosqichlari.

1 Saytda qanday ko'rinadi UI demo

Anonim forma yoniga shunday tugma qo'yiladi. Bosilganda Telegram'dagi botingiz ochiladi — odam to'g'ridan-to'g'ri yozadi.

Telegram'da anonim yozish Tugma → t.me/JMPortfolio_bot (test uchun; Livegram boti bilan almashtiriladi)
2 Livegram'ni sozlash (≈5 daqiqa) Telegram'da

Hammasi Telegram ichida — kod yo'q. Tavsiya: forma uchun ishlatayotgan @JMPortfolio_botga tegmaslik uchun yangi bot oching.

1@BotFather oching → /newbot → nom bering → yangi token oling (masalan chat uchun alohida bot).
2@LivegramBot oching → Start → "Add bot / Bot qo'shish" → yuqoridagi tokenni joylashtiring.
3Livegram salom xabari va sozlamalarni so'raydi — tayyor. Endi botingiz "feedback bot" bo'ldi.
4Saytdagi tugmani shu yangi bot manziliga yo'naltirasiz (masalan t.me/JMPortfolio_chat_bot).
3 Javob qanday boradi ikki tomonlama

Odam botga yozadi → sizga (bot egasiga) yetadi. Siz o'sha xabarga reply qilib javob berasiz → unga anonim qaytadi.

🕵️ Anonim foydalanuvchi → sizgaAssalomu alaykum, loyiha bo'yicha savol bor edi…
Siz (reply qilib)Salom! Albatta, eshitaman 🙌
🕵️ Anonim → sizgaRahmat! Narxni ayta olasizmi?

Siz uning ism/username'ini ko'rmaysiz — faqat xabar. Reply qilsangiz, javob unga yetadi.
